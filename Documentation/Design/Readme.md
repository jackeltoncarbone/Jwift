# Design Foundation

The consolidated reference for Jwift's Apple-like (iOS / iPadOS 26 *Liquid
Glass*) design language. Build against these three; the raw research they were
distilled from lives in [`../Research/Sources/`](../Research/Sources).

- **[Aesthetic.md](Aesthetic.md)** — the visual language: materials (Liquid /
  Solid Glass), concentric radii, color, typography, spacing, motion, the
  iOS 18→26 delta, and anti-patterns. *What it looks like.*
- **[Layout.md](Layout.md)** — how surfaces compose into an app, and the drill
  editor specifically (canvas-first, two-helpers-max, reflow per platform).
  *How it's arranged.*
- **[Components.md](Components.md)** — recurring component behaviors: chrome
  bars, buttons/controls, sheets & detents, popovers, transport/mini-player,
  multimodal text input, multi-step flows. *How the pieces behave.*

Refreshed June 2026 (Liquid Glass is the shipped, App-Store-mandatory system
language across iOS/iPadOS/macOS 26).
